# Grilli - Premium Restaurant Website

A responsive, multi-page frontend website for a luxury dining restaurant. Built with vanilla HTML5, CSS3, and JavaScript, focusing on smooth UI transitions and clean typography.


**Live Demo:** [https://gentle-blancmange-aa41eb.netlify.app/](https://gentle-blancmange-aa41eb.netlify.app/)

---

## Features

* **Responsive Layout:** Works across mobile, tablet, and desktop viewports using CSS Flexbox and Grid.
* **Interactive UI Elements:** Vanilla JS handles the mobile navigation drawer, image sliders, and smooth scroll behaviors.
* **Design System Baseline:** Styled according to a strict design guide using consistent color variables and type scales.
