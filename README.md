# Grilli - Premium Restaurant Website

A modern, fully responsive, and visually stunning restaurant website designed to provide an exceptional user experience. This project showcases smooth animations, clean layouts, and optimization for both mobile and desktop platforms.

**[Live Demo](https://gentle-blancmange-aa41eb.netlify.app/)**

---

##  Features

 **Fully Responsive Design:** Seamless browsing experience across mobile, tablet, and desktop devices.
 **Modern UI/UX:** Clean, elegant typography and high-quality imagery crafted specifically for a luxury dining theme.
 **Dynamic Interactions:** Clean JavaScript implementations for interactive elements (such as navigation toggles, sliders, or smooth scrolling).
 **Performance Optimized:** Clean code architecture ensuring fast loading speeds.
 **Maintainable Architecture:** Modularized file styling following strict design system guidelines.


##  Project Structure

The codebase is organized cleanly to allow for easy scalability and maintenance:


Grilli/
├── assets/
│   ├── css/

│   └── js/
